IMPORTANTE
Caricare tutti e quattro i file allo stesso livello nella cartella principale
del repository. Non rinominare le immagini, perché index.html utilizza questi
nomi esatti.

PUBBLICAZIONE SU GITHUB PAGES
1. Creare un nuovo repository pubblico.
2. Caricare insieme index.html, dojo.png, mate.png e carl.png.
3. Aprire Settings > Pages.
4. In Build and deployment scegliere Deploy from a branch.
5. Selezionare il branch main e la cartella /(root), quindi Save.

PRIVACY
I progressi sono salvati soltanto nella memoria locale del browser. Nessun dato
viene inviato all'autrice. L'informativa completa è disponibile nell'app.
